# وين راحت المصاريف؟ — متتبع الدخل والمصاريف

تطبيق عربي باتجاه كتابة من اليمين إلى اليسار (RTL) لإدارة الدخل والمصاريف باستخدام HTML وCSS وJavaScript.

## تشغيل المشروع
1. فكّي ضغط ملف المشروع كاملًا.
2. افتحي مجلد `Qafza_Workshop`.
3. افتحي `index.html` باستخدام المتصفح.
4. يحتاج تحميل خط Tajawal وأيقونات Font Awesome إلى اتصال بالإنترنت، لكن وظائف التطبيق الأساسية تعمل محليًا.

## الميزات
- عرض العمليات التجريبية الموجودة في `js/data.js`.
- حساب إجمالي الدخل والمصاريف والرصيد المتبقي.
- إضافة دخل أو مصروف، مع التحقق من الحقول والمبلغ.
- تعديل العمليات وحذفها مع طلب تأكيد قبل الحذف.
- البحث في العناوين والفئات.
- التصفية حسب نوع المعاملة والفئة والفترة (آخر 7 أيام أو الشهر الحالي).
- حفظ العمليات في `localStorage` لتبقى بعد تحديث الصفحة في المتصفح نفسه.
- استعادة البيانات التجريبية من زر «إعادة تعيين البيانات».
- تنسيق المبالغ بالدينار الأردني (د.أ).

## الملفات
- `index.html`: هيكل الصفحة.
- `css/style.css`: التصميم والتنسيق.
- `js/data.js`: بيانات البداية التجريبية.
- `js/app.js`: وظائف التطبيق.

## ملاحظات
- البيانات محفوظة في المتصفح نفسه باستخدام `localStorage`، وليست قاعدة بيانات على الإنترنت.
- زر إعادة التعيين يستبدل البيانات الحالية بالبيانات التجريبية الأصلية بعد طلب التأكيد.
- عند التسليم، ارفعي المجلد كاملًا إلى مستودع GitHub عام أو خاص حسب تعليمات الورشة.
